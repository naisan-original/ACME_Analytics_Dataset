# ACME Analytics Synthetic Dataset

> ## WARNING: THIS IS A SYNTHETIC DATASET. NOTHING IN IT IS TRUE.
>
> **ACME Analytics is a fictional company, and every record in these files was generated by a computer program.**
>
> - **Real company names appear for realism only.** Their presence does not mean a company is, or ever was, a customer, prospect or partner of anyone.
> - **All commercial data is invented.** That includes customer status, churn, contracts, ARR, seats, pricing, usage, API activity, sentiment and touchpoint notes.
> - **Nothing here describes the actual business, finances, technology, satisfaction or decisions of any real company.** A row showing a company as churned, contracting or unhappy is fiction.
> - **Company attributes are not reliable.** Revenue bands, employee bands, industries, ranks and locations are approximate or randomly assigned.
> - **Employee names are fictional.** About 40% of company names are fictional too.
> - **No real company has reviewed, endorsed or sponsored this dataset.**
>
> **Use it only for testing and learning analytics tools.** Do not use it for research about these companies, sales or marketing, investment, credit or any other real-world decision. If you share these files, keep this notice with them.

## Before you load it

- **`region` uses `NA` for North America.** Many tools read `NA` as null by default, so check it on import. In pandas, use `keep_default_na=False, na_values=[""]`.
- **`user_usage_month` is a sample.** Multiply measures by `sample_weight` to estimate full-population totals.
- **Every satellite table joins directly to the central fact.**
- **Company names contain commas,** so use a real CSV parser.
